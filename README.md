# NPTEL Deep Learning for Computer Vision - PYQ Quiz Master

An interactive, high-performance web application designed for students and practitioners preparing for the **NPTEL Deep Learning for Computer Vision (IIT Hyderabad, Course Code: NOC25-CS93)** certification examination.

Deployed with zero build steps — ready for instant deployment on **Vercel**, **Netlify**, or **GitHub Pages**.

---

## 🌟 Key Features

- **15 Structured 10-Page Blocks**: Covers all **143 pages** of the official NPTEL PYQ and assignment repository.
- **336 Verified Questions**: Includes both conceptual MCQs and weekly programming assignments with official accepted answer keys.
- **Dual Quiz Modes**:
  - **Study & Practice Mode**: Instant answer check with detailed mathematical explanations and PDF page references.
  - **Timed Exam Mode**: Countdown timer, palette navigator, and question flagging for realistic exam simulation.
- **Comprehensive Final Mock Test**: 30 questions drawn randomly from all 15 blocks.
- **Question Navigator Drawer**: Visual palette tracking answered, pending, and flagged questions.
- **Instant Search / Question Bank (`Ctrl + K`)**: Real-time fuzzy keyword search across all 336 questions.
- **Performance Analytics**: Circular score donut, accuracy metrics, and a "Retry Mistakes Only" mode.
- **Synthesized Audio Feedback**: Built-in sound effects using Web Audio API (no external sound files required).
- **Modern Glassmorphic Dark & Light Modes**: Responsive across desktop, tablet, and mobile devices.

## 🚀 Deployment

### Deploy to Vercel
1. Fork or push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Deploy! (No build settings or environment variables required).
